# poker

視窗程式設計(II)上課範例，

德州撲克牌組，按下發牌隨機抽取5張牌，抽取後可點牌選取換一次牌，可換多張，按下判斷牌後會在旁邊的label顯示最佳結果。

整個流程結束後，可再按下發牌重新開始。
