# poker

視窗程式設計(II)上課範例，

德州撲克牌組，需先下注才能發牌，按下發牌隨機抽取5張牌，抽取後可點牌選取換一次牌，可換多張，按下判斷牌後會在旁邊的label顯示結果，若有對子以上結果可以獲得獎金（只有雜牌會扣錢）。


整個流程結束後，可再按下發牌重新開始。
